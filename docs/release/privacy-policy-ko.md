# Twelve Count 개인정보 처리방침

최종 업데이트: 2026-09-08

Twelve Count는 오프라인 싱글 플레이 게임입니다. 현재 버전은 개발자가 운영하는 서버에 사용자의 개인정보나 플레이 데이터를 전송하지 않습니다.

## 1. 수집하는 정보

현재 버전의 Twelve Count는 개발자가 직접 다음 정보를 수집하지 않습니다.

- 이름, 이메일 주소, 전화번호 등 연락처 정보
- 계정 또는 로그인 정보
- 위치 정보
- 연락처, 사진 또는 미디어 라이브러리 정보
- 카메라 또는 마이크 데이터
- 광고 식별자
- 결제 또는 금융 정보
- 사용자 콘텐츠
- 게임 플레이 분석 또는 맞춤형 광고 데이터

## 2. 게임 진행 데이터

복서 정보, 커리어 진행, 경기 상태 등 게임 저장 데이터는 기기의 앱 샌드박스에 로컬로 저장됩니다. 해당 데이터는 Twelve Count 개발자 서버로 전송되지 않습니다.

기기의 운영체제 및 Apple 백업 설정에 따라 앱 데이터가 기기 백업에 포함될 수 있습니다. 이 경우 백업 처리에는 Apple의 정책이 적용됩니다.

## 3. 인터넷 연결 및 외부 서비스

현재 버전은 게임 플레이를 위해 인터넷 연결을 요구하지 않으며 다음 기능을 사용하지 않습니다.

- 광고 네트워크
- 분석 SDK
- 소셜 로그인
- 멀티플레이 서버
- 클라우드 게임 계정
- 푸시 알림
- 인앱 결제 또는 구독

App Store 자체의 구매, 다운로드, 결제, 영수증, 업데이트 및 플랫폼 운영 과정에서 Apple이 처리하는 정보에는 Apple의 개인정보 보호정책이 적용됩니다.

## 4. 아동의 개인정보

Twelve Count는 개발자 서버로 개인정보를 수집하거나 전송하지 않습니다. 향후 개인정보를 처리하는 온라인 기능을 추가하는 경우, 출시 전에 이 방침을 갱신하고 필요한 보호 조치를 적용합니다.

## 5. 방침 변경

게임의 데이터 처리 방식이 변경될 경우 이 문서를 업데이트하고 최종 업데이트 날짜를 변경합니다. 특히 분석, 온라인 기능, 계정, 광고 또는 외부 SDK가 추가되는 경우 App Store 개인정보 공개 내용과 본 방침을 함께 재검토합니다.

## 6. 문의

개인정보 관련 문의는 App Store 제품 페이지에 게시되는 공식 지원 채널을 통해 접수합니다.
