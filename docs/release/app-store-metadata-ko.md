## Description

복싱은 링 위에서만 결정되지 않습니다.

Twelve Count는 한 명의 복서를 처음부터 끝까지 키워 나가는 싱글 플레이 복싱 커리어 게임입니다. 훈련과 휴식, 체중 관리, 파이트머니, 부상과 피로를 관리하고, 다음 상대를 고른 뒤 스카우팅 리포트를 읽어 경기 전략을 결정합니다.

경기에서는 잽, 강타, 바디, 가드, 카운터 중 다음 행동을 선택합니다. 상대의 스타일과 텔을 읽고 위험한 교환을 피할지, 체력을 깎을지, 한 번의 카운터를 노릴지 판단해야 합니다.

주요 특징

• 한 명의 복서에 집중하는 커리어 진행
• 매 캠프마다 훈련·회복·체중 관리 중 선택
• 상대별 스카우팅과 게임 플랜
• 잽·강타·바디·가드·카운터 기반의 선택형 복싱
• 승리, 판정, KO, 부상, 피로, 랭킹과 은퇴까지 이어지는 커리어
• 인터넷 연결 없이 플레이 가능한 오프라인 싱글 플레이
• 광고 없음
• 인앱 결제 없음
• 구독 없음

링에 오르기 전의 선택까지 포함해, 한 복서의 인생을 끝까지 운영하세요.
