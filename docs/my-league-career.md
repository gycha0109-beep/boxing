# TWELVE COUNT · 한 선수의 커리어

한 선수를 만들어 경기와 제한된 관리 기회를 반복하고, 네 경기마다 다음 시즌의 계약을 선택한다. 2006프로야구의 개인 육성, 성적에 따른 이벤트, 연봉 협상을 복싱 일정으로 옮긴다. [게임조선](https://m.gamechosun.co.kr/news/view.php?no=160696) · [GG게임](https://www.ggemguide.com/mobile/1047/)

| 진행 | 이전 | 변경 |
| --- | --- | --- |
| 데뷔 | 스타일과 무작위 재능 | 이름과 배경을 정하고 스타일 선택, 재능 확인 |
| 경기 사이 | 장비 구매와 훈련 병행 | 훈련·회복·감량·장비·매니저 활동 중 한 번 |
| 대진 | 포인트 구간과 사다리 | 실력·랭킹·최근 성적에 맞춘 대진, 흥행 제안과 타이틀 자격 분리 |
| 경기 주간 | 전술 → 컨디션 → 분석 → 플랜 | 상대 분석에서 플랜 선택 → 계체 → 기존 3라운드 전투 |
| 정산 | 성적과 이벤트 → 캠프 | 정산과 상황별 이벤트 → 4경기마다 평가·계약 → 관리 |
| 장기 목표 | 세계 타이틀 획득으로 종료 | 12번째 공식 경기 평가, 세계 타이틀 획득 후 은퇴 또는 최대 3회 방어 |

인기는 기존 평판, 실력은 다섯 전투 능력치, 랭킹은 커리어 포인트에서 계산한다. 한 선수의 기록·계약은 은퇴 시 끝나고, 유산 슬롯과 세계의 왕좌 기록은 다음 세대로 이어진다. 36전 상한과 기존 건강·경제·패전 은퇴 기준을 유지한다. 튜토리얼의 분모 12는 안내 단계다.

## 계약과 은퇴 기준

첫 계약 이후 파이트머니 기본 비율은 안정 110%, 도전 135%, 흥행 120%다. 랭킹은 재계약 조건에, 인기는 흥행 계약과 개별 경기의 제안 금액에 반영한다. 선수가 상대를 선택하면 제안 금액을 고정하고, 실제 정산 때 계체 결과와 기존 재능 배율을 적용한다. 6연패 이상이면서 경기 후 건강이 30 이하이면 누적 18패 전에도 은퇴한다. 세계 타이틀 획득으로 유산 슬롯 4개, 세 번째 방어 성공으로 5개가 열린다. 선수 챔피언이 은퇴하면 기존 명단에서 후임을 세우고 왕좌 기록을 보존한다.

## 검증 · 2026-11-21

기준 브랜치는 `feat/first-cycle-guided-tutorial-20261121`, 변경 전 HEAD는 `c4a4fac`이다. 아래 수치는 같은 Python 시뮬레이터의 시드 1~10,000을 변경 전후에 실행한 결과다. 변경 후 세 배경을 순환하고, 회복·감량이 필요하면 장비 구매보다 우선하는 정책을 사용했다. 챔피언 달성률에는 방어전에서 패한 선수도 포함한다.

| 지표 | 변경 전 | 변경 후 |
| --- | ---: | ---: |
| 세계 챔피언 달성 | 3.9% | 6.4% |
| 평균 공식 경기 | 28.52 | 29.32 |
| 누적 18패 은퇴 | 91.4% | 86.8% |
| 연패·손상 복합 은퇴 | 해당 없음 | 3.4% |

- Godot 4.7.2 Stable에서 실제 첫 경기 입력·정산, 전투 중 저장과 같은 교환 복귀, 배경별 첫 추천 상대, 활동 중복 방지, 4·8·12전 계약, 13번째 경기 진행을 확인했다. 장기 분기는 고정 결과를 입력해 12번째 경기 은퇴, 챔피언 은퇴 선택, 3회 방어, 유산 선택과 다음 세대의 왕좌 기록을 검증했다.
- 저장은 기존 v1·v2 마이그레이션, v3 백업 복구, 예전 준비 단계에서 분석 복귀를 검사했다. 프로젝트에 있던 1전 결과 저장본은 복사본으로 Windows에서 열었다. 테스트마다 별도 사용자 디렉터리를 썼다.
- Windows 네이티브에서 390·430·560px 폭으로 계약·튜토리얼·전투 HUD를 검사했다. HTML 릴리스는 Edge에서 390×845, 430×932, 560×1213으로 새 게임을 시작하고 스타일을 선택해 재능 화면까지 진입했다. Windows x64 릴리스도 실행했다.
- v21 훈련·v24 계체 테스트는 변경 전 빠른 씬 교체 중 Windows 접근 위반을 재현했다. 씬 해제와 다음 복원 사이 정리 시간을 둔 후 Windows 네이티브에서 각각 3회 연속 통과했다. 엔진 내부 원인은 미확정이다. 일부 테스트 종료 시 리소스 경고가 남고, Windows 내보내기에서는 메인 스크립트가 경로로 정상 로드되면서 UID 경고가 기록된다.
- Python 검증은 `python -X utf8 tools/test_data.py`, `tools/test_gameplans.py`, `tools/test_career_logic.py`, `tools/simulate_careers.py`, `tools/project_sanity.py`를 같은 방식으로 실행한다. 커리어 전환 검증은 격리된 `APPDATA` 아래에 `_sandbox_user_data` 디렉터리를 두고 `godot --path . --script res://tests/league_career_smoke.gd`로 재현할 수 있다.

프로젝트의 `PLAY_WEB.cmd`는 `build/web/my-league/index.html`을 로컬 서버로 연다. Windows 빌드는 `build/windows/TwelveCount.exe`에서 실행한다.
