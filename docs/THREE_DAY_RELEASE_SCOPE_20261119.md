   https://store.steampowered.com/app/1161590/Punch_Club_2_Fast_Forward/

원본 제품 기준: docs/design-reference-gladiator-manager.md 및 Twelve_Count_Legacy_World_Meta_Design_v1.md.

## 절대 고정할 플레이 흐름
시작 → 스타일/재능 → 캠프/장비 → 계약/상대 분석 → 게임플랜/계체 → 전투 → 결과/피로/부상 → 은퇴 → 유산 1개 선택 → 2세대 시작.
- 모든 버튼은 실제 작동하거나 사용 불가 이유가 화면에 명확히 보일 것.
- 메뉴 전환은 실제 커리어 상태를 임의 변경하지 않을 것.
- 20~30분 1회차, 2세대 진입·유산 효과의 실질 검증.
- 읽을 수 있는 게임플랜 상성, 위협적인 챔피언, 누적 커리어 손상.
- 중간 강제 종료/새로고침 이후 저장·복귀.
